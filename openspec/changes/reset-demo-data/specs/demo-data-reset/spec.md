## Purpose

배포 담당자가 현재 배포 버전의 시연 데이터를 확인하고, 명시한 대상만 반복해서 같은 기준 상태로 되돌릴 수 있게 한다.

## ADDED Requirements

### Requirement: 대상 확인과 미리보기
워크플로는 지정한 시연 대상과 배포 버전을 확인하고 기본 동작으로 읽기 전용 미리보기를 제공해야 한다(SHALL).

#### Scenario: 기본 실행
- **WHEN** 담당자가 미리보기를 실행한다
- **THEN** 대상과 배포 SHA 및 변경 예상 건수를 보여주고 DB와 앱 상태를 유지한다.

#### Scenario: 대상 불일치
- **WHEN** 허용된 DB, 배포 버전 또는 초기화 확인 입력이 일치하지 않는다
- **THEN** 데이터를 변경하기 전에 실행을 중단한다.

### Requirement: 원자적인 시드 복원
워크플로는 확정된 범위를 동일한 배포 시드 상태로 복원하고 범위 밖의 행을 보존해야 한다(SHALL).

#### Scenario: 초기화 성공과 재실행
- **WHEN** 테스트 대화가 누적된 대상에 복원을 두 번 실행한다
- **THEN** 두 실행 모두 대상의 행 ID, 내용과 관계가 시드와 일치하며 서비스가 조회 요청에 응답한다.

#### Scenario: 저장 중 실패
- **WHEN** 삭제 후 시드 적용 또는 커밋 전 검증이 실패한다
- **THEN** 삭제 이전 상태로 롤백하고 앱 재기동과 실패 원인을 보고한다.
