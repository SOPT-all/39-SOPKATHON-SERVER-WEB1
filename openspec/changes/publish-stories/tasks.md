각 항목의 구현·검증이 끝난 경우만 완료 표시하고 기능 단위로 작은 커밋을 유지한다.

## 1. 계약과 처리 권한

- [ ] 1.1 CreateStoryRequest와 검증된 최종값, UUID·필드 타입·공백·길이·카테고리 검증, 고정 순서 본문 해시를 구현한다. 단위 테스트로 JSON 순서 독립성·원문 포함·경계·각 오류 코드를 확인한다.
- [ ] 1.2 Story의 해시·토큰·만료, 잠금/관찰 repository, Clock·유한 대기 설정과 coordinator를 구현한다. 처리 권한·공개 재사용·충돌·원문 불일치·소유권과 만료 조건을 테스트한다.

## 2. 생성과 원자적 확정

- [ ] 2.1 OpenAI 공통 통신을 재사용하도록 분리하고 StoryOpeningGenerator의 strict scene/question 출력·유효성 검증을 구현한다. 대역 HTTP 테스트로 최종값 전달·잘못된 결과·실패 변환을 확인하고 첫 API의 기존 테스트를 유지한다.
- [ ] 2.2 ChatRepository와 별도 transactional 확정 writer, 트랜잭션 밖 생성·대기 orchestration을 구현한다. 테스트로 원문·ID 유지, 최종값·메시지·상태의 원자적 반영과 토큰 정리를 확인한다.

## 3. HTTP와 통합 검증

- [ ] 3.1 공개 POST /api/v1/stories와 201/200 응답·Swagger·409 메시지를 구현한다. MVC 테스트로 헤더·본문 오류·404·400 원문 차이·415·503·500 및 동일 본문 재시도를 확인한다.
- [ ] 3.2 H2 MySQL 모드의 병렬 트랜잭션 테스트로 동일 동시 요청 AI 1회·메시지 1건, 진행 중 다른 본문 409, AI 실패·저장 실패·대기자 실패, 만료 회수와 이전 토큰 저장/해제 차단을 확인한다.
