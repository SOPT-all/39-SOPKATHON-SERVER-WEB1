# Spec Delta

## Purpose

사용자가 녹음에서 만든 세계관과 그 안의 채팅·맥락을 서로 연결해 보관한다. 각 데이터의 식별자와 원문을 유지하고 필수 소속 관계 및 ERD의 길이 제한을 지켜 후속 기능에서 일관되게 조회하도록 한다.

## ADDED Requirements

### Requirement: 녹음과 세계관 저장

시스템은 녹음의 원문·UUID와 세계관의 제목·카테고리·배경·배경 요약·인물·사건·첫 장면·이미지 URL을 고유한 자동 생성 식별자와 함께 저장해야 한다(SHALL). 세계관 카테고리는 공포·로맨스·스릴러·액션·판타지·기타를 표현해야 한다(SHALL).

#### Scenario: 세계관 데이터 조회
- **WHEN** 녹음과 그에 속한 세계관을 저장하고 다시 조회한다
- **THEN** 식별자, 원문, UUID와 모든 세계관 속성이 보존된다

### Requirement: 필수 소속 관계

세계관은 반드시 하나의 녹음을 참조하며 녹음 하나에는 최대 하나의 세계관만 연결되어야 한다(SHALL). 채팅과 맥락은 반드시 하나의 세계관에 속하며 같은 세계관에 여러 채팅과 맥락을 저장할 수 있어야 한다(SHALL). 존재하지 않는 상위 식별자와 상위 관계 없는 데이터는 거부해야 한다(MUST).

#### Scenario: 같은 녹음에 중복 세계관 저장
- **WHEN** 이미 세계관이 연결된 녹음을 참조하여 두 번째 세계관을 저장한다
- **THEN** 유일성 제약 위반으로 저장에 실패한다

#### Scenario: 세계관 생성 전 녹음 저장
- **WHEN** 세계관을 생성하기 전에 녹음만 저장한다
- **THEN** 녹음 저장에 성공한다

#### Scenario: 여러 하위 데이터 보관
- **WHEN** 서로 다른 녹음에 세계관을 각각 저장하고 같은 세계관에 두 채팅·두 맥락을 저장한다
- **THEN** 모든 하위 데이터가 중복 제한 없이 저장되고 올바른 상위를 가리킨다

#### Scenario: 필수 상위 관계 누락
- **WHEN** 상위 관계를 지정하지 않거나 존재하지 않는 상위 식별자로 저장한다
- **THEN** 저장에 실패한다

### Requirement: 데이터 길이와 선택 속성

시스템은 세계관 제목 20자, 배경 200자, 배경 요약 200자, 인물 100자, 사건 500자, 첫 장면 300자, 이미지 URL 300자의 제한을 지켜야 한다(SHALL). 녹음 원문·채팅 내용·맥락 내용은 TEXT로 저장하고 PK·FK 이외의 속성은 null을 허용해야 한다(SHALL).

#### Scenario: 긴 원문과 선택 속성
- **WHEN** 255자를 초과하는 원문·채팅·맥락을 저장하거나 선택 속성을 비워 저장한다
- **THEN** 원문이 잘리지 않고 보존되며 선택 속성이 없는 데이터도 저장된다

#### Scenario: 세계관 제목 길이 초과
- **WHEN** 21자 제목으로 세계관을 저장한다
- **THEN** 길이 제한 위반으로 저장에 실패한다

#### Scenario: 배경 요약과 이미지 URL 저장
- **WHEN** 200자 배경 요약과 300자 이미지 URL을 저장하고 다시 조회한다
- **THEN** 두 값이 잘리지 않고 보존된다

#### Scenario: 배경 요약과 이미지 URL 길이 초과
- **WHEN** 배경 요약을 201자 또는 이미지 URL을 301자로 지정해 저장한다
- **THEN** 길이 제한 위반으로 저장에 실패한다

### Requirement: 타입 보존

시스템은 세계관 카테고리와 채팅·맥락 타입을 순번에 의존하지 않는 문자열 값으로 저장해야 한다(SHALL). 채팅 타입은 STUDENT/STORY/FEEDBACK, 맥락 타입은 CHARACTER/EVENT를 지원해야 한다(SHALL).

#### Scenario: 타입 재조회
- **WHEN** 타입을 지정한 세계관·채팅·맥락을 저장하고 다시 조회한다
- **THEN** 저장 전과 동일한 타입을 복원한다
